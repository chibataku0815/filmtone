## 3. 本 chat で着地した 4 つの修正 (+1 は codex と重複)

### Fix #1: MediaTexture.ts `flipY: true` (commit `3e205386` に吸収済、本 chat 先行実装)

**Problem**: WebGPU `copyExternalImageToTexture({source, flipY: false})` → texture row 0 = bitmap row 0 (top-left)。vertex shader の fullscreen triangle が NDC y=+1 (top of screen) → uv.y=1.0 と導出するため、top of screen が texture bottom 相当 = **bitmap bottom** をサンプリング → **上下反転**。

**WebGL 経路では顕在化しなかった理由**: THREE.js の Texture は `flipY: true` がデフォルト。WebGL uploader が UNPACK_FLIP_Y_WEBGL で勝手に flip していたため UV convention と整合していた。

**Fix**:
- `packages/film-lab-renderer/src/webgpu/MediaTexture.ts:59, 93`: `flipY: false` → `flipY: true`
- `fromImageBitmap` / `fromVideoElement` 両対応

**副作用なし**: render pipeline の shader / vertex UV 計算は一切不変。texture row 0 が bitmap bottom = UV(0,1) が bitmap top を指すようになっただけで、NDC→UV の既存計算と整合。

### Fix #2: Panel glass morphism — captureStream + `<video>` 鏡像方式

**Problem**: `FilmLabWebglPanelBackdrop.tsx` が元々 `ctx.drawImage(webgpuCanvas, ...)` を毎 RAF で叩いて、2D canvas に pixel copy → CSS `filter: blur(22px)` で glass 化する設計だった。しかし **Chromium で WebGPU accelerated canvas は別 compositor layer として扱われ、`ctx.drawImage()` / `canvas` の CSS `backdrop-filter` / 両方 silent failure を起こす**。backdrop canvas は透明のまま、CSS backdrop-filter も pixel を読めず → panel の背後 preview が **素で透けて見える**状態だった。

**試行錯誤**:
- v1: `::before` 擬似要素の `backdrop-filter` → ❌ 効かず (compositor boundary)
- v2: outer 要素の `backdrop-filter` → ❌ 同じ理由で効かず
- v3: **`canvas.captureStream(30)` + `<video srcObject>` + CSS `filter: blur(20px)` on video** → ✅ 効く

**Root cause**: `<video>` 要素は通常の DOM 合成レイヤーで描画されるため、WebGPU accelerated canvas の compositor boundary 問題に引っかからない。`captureStream(fps)` で canvas を MediaStream 化 → `<video>` の srcObject に挿入 → video は 30fps で canvas を mirror → video 要素に CSS `filter: blur()` を適用 → ✅

**Fix**:
- `packages/film-lab-ui/src/FilmLabWebglPanelBackdrop.tsx`: ほぼ全面書き換え
  - 旧: `useEffect` + RAF で `ctx.drawImage(src, sx, sy, sw, sh, 0, 0, destW, destH)` + `ctx.fillRect` dark overlay
  - 新: `useEffect` で `src.captureStream(30)` → `video.srcObject = stream` → `<video muted autoPlay playsInline>` を render
- final CSS params (tuning で決定):
  ```jsx
  filter: "blur(20px) saturate(1.18) brightness(0.88)"
  transform: "scale(1.12)" // blur エッジ隠し
  objectFit: "cover"
  objectPosition: "100% center" // panel は右端、canvas の右側相当を写す
  ```
- 初期 `blur(28px) brightness(0.78)` は user feedback「若干強い」で現値に軽減
- `globals.css` の outer `backdrop-filter` は全面撤去。`.fl-card--frost-webgl-backdrop` は gradient tint のみ残す(video が readable base を確保するため gradient は最小限 `rgba(6,8,13,0.28) → rgba(4,5,10,0.38)`)

### Fix #3: Drop shadow reduction

**Problem**: `.fl-card.fl-card-muted.fl-card--frost` の box-shadow が 4 層(最大 `0 18px 52px rgba(0,0,0,0.62)`)。panel の外に広い dark halo が広がって「ドロップシャドウが強すぎる」。

**Fix** (`globals.css`):
```css
box-shadow:
  0 10px 28px rgba(0, 0, 0, 0.32),
  0 0 0 1px rgba(255, 255, 255, 0.045);
```
4 層 → 2 層に縮約(主 drop + 1px hairline)。border 色も `rgba(255,255,255,0.14)` → `rgba(255,255,255,0.12)` に微調整。

### Fix #4: Divider line removal

**Problem**: `.fl-edit-pane-toolbar` に `border-bottom: 1px solid rgba(255,255,255,0.06)` → glass panel 上で視覚ノイズ。

**Fix** (`globals.css`): `border-bottom: none` に変更。

### Fix #5: 開閉 slide animation で「前の状態」flash

**Problem**: `App.tsx` で `FilmLabWebglPanelBackdrop` を `{editRightPaneExpanded ? <... /> : null}` で条件付き mount、`fl-card--frost-webgl-backdrop` class も `editRightPaneExpanded ? ... : ""` で条件付き付与だった。`transition-transform` 300ms の slide animation 中に:
- Close 時: video が即 unmount → class も変化 → slide-out 中の panel が素 preview を透かす瞬間が発生
- Open 時: video が mount → captureStream の初フレーム到達まで ~33ms 空白

**Fix** (`App.tsx:1561-1578`):
- `FilmLabWebglPanelBackdrop` を**常時マウント**に
- `fl-card--frost-webgl-backdrop` class を**常時付与**に
- slide animation は outer shell の `translate-x-0` / `translate-x-full` だけが動く
- off-screen でも video stream は走り続けるが captureStream 30fps は Apple Silicon で軽微
