# Filmtone Desktop App Privacy Draft

Use this as the App Store Connect App Privacy answer set for the current
local-first macOS build.

- Data Collection: Data Not Collected
- Tracking: No
- Third-party advertising: No
- Login or account creation: No
- Cloud sync: No
- Analytics SDKs: None in the macOS app target

This file is intentionally not uploaded by the API-key fastlane lane. Apple's
App Privacy form may require an Apple ID/Admin session or App Store Connect UI
access, so keep the answer explicit instead of letting release automation invent
privacy state.
