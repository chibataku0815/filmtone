このリリースでは、iPhone で撮影して、そのまま映画調の色づくりへ進める録画フローを追加しました。撮影画面から 4K24 の ProRes 422 HQ / Apple Log 2 収録を行い、手ぶれ補正を使った映像を Filmtone の編集画面へ渡せます。

外部 SSD を選んだ場合は高品質な master を SSD 側に残し、iPhone 内では軽い proxy を使って編集します。大きな素材を本体に抱え込みすぎず、Look の確認、調整、書き出しへ進める構成です。SSD がない場合は短い内部録画として扱い、状態が分かるようにしています。

撮影画面も作り直しました。Look、レンズ、ISO、シャッター、露出補正、ホワイトバランスを撮影前に確認しやすくし、必要な時だけ細かい値を触れる cockpit 型の UI にしています。Stone / Urban などの Look は撮影中のプレビューにも反映され、撮ったあとに編集画面へ戻った時も選択が引き継がれます。

書き出し側では、capture package の master / proxy のどちらを使ったかを Sidecar に残すようにしました。外部 SSD の master が使えたのか、proxy fallback になったのかを後工程で確認しやすくしています。

そのほか、空の画面とオンボーディングの見た目を Apple Liquid Glass の方向に揃え、フォトライブラリ、ファイル、録画の入口を整理しました。
