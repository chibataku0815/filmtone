# M12 / S12-F Device Verify Run Sheet

Date: 2026-05-08 JST
Target: iPhone 17 Pro / iOS 26.4(.x)

S12-A〜S12-E が landed (`b0b33c2e` まで)。S12-F は実機 4 run +
`scripts/verify-m12-capture-master.sh` で master truth + M12 package
field を確定させる。

## 走らせる順序

| # | Profile         | Lens   | Exposure | WB     | 追加操作                                     |
|---|-----------------|--------|----------|--------|----------------------------------------------|
| 1 | `wide-auto`     | 1×     | Auto     | Auto   | Look 任意。何もしない or tap-to-focus 1 回   |
| 2 | `wide-manual`   | 1×     | Manual   | Locked | ISO / shutter を slider で少し動かす         |
| 3 | `tele-auto`     | 5×（or 端末で出ている Tele） | Auto     | Auto   | —                                            |
| 4 | `ultraWide-auto`| 0.5×   | Auto     | Auto   | —                                            |

各 run は **5〜10 秒** で十分。長く撮る必要なし。

## UX チェック(全 run 共通)

- recording 中に lens swap / exposure mode toggle / WB toggle が **disabled**
- recording 中も EV slider / tap focus / WB lock toggle / manual ISO+shutter slider は **enabled**(seamless 適用)
- Manual に入った瞬間に画が急に飛ばない(auto 値 inherit)
- 180° marker (1/48s) が shutter slider に **黄色 tick** で見える
- Auto に戻す導線(segmented 左ピル)が常に見える
- Manual 中に EV slider / metering POI(tap-to-meter)が **見えない / 効かない**
- Manual 中でも tap-to-focus は効く(reticle 出る)

## Verify コマンド(各 run のあと)

```bash
cd /Volumes/SamsungPortableSSDX5001/documents/forestone/filmtone/.claude/worktrees/feature+ios-m9-recording-export-completion/apps/capacitor-film-lab-ios

# device から package を取ってくる(SSD mode なら external folder を直接読める)
PKG=/path/to/captures/<id>/

./scripts/verify-m12-capture-master.sh wide-auto      "$PKG"
./scripts/verify-m12-capture-master.sh wide-manual    "$PKG"
./scripts/verify-m12-capture-master.sh tele-auto      "$PKG"
./scripts/verify-m12-capture-master.sh ultraWide-auto "$PKG"
```

`xcrun devicectl device copy from --device <UDID> --source <on-device path> --destination <local path>` で package を取り出せる(M11 と同じ手順)。

## Gate(全 run で PASS が必要)

各 run の出力末尾が `S12-F GATE PASS — profile=<profile>` なら OK。
失敗時は `MASTER TRUTH GATE FAIL` または `M12 PACKAGE GATE FAIL` が出る。

### Master truth(M10 baseline、全 run 同じ)

- `codec_tag = apch`
- `pix_fmt = yuv422p10le`
- `width × height = 3840 × 2160`
- `frame_rate = 24/1`
- `parametersCodec = "ProRes422HQ"`
- `parametersColorSpace = "Apple Log 2"`
- `parametersStabilization = "cinematicExtendedEnhanced"`
- `schemaVersion = 2`
