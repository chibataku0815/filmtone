## Goal

Native Desktop v2 preview に source vs graded の Before/After 比較を追加する。

- 固定 50:50 split (左 = source、右 = graded)
- still preview と AVPlayer video preview の両方で動作

- compare ON/OFF はプレビューのみに作用、export / sidecar には影響しない

## Shortcut safety

- `V` は modifier なし toolbar shortcut。SwiftUI の `.keyboardShortcut("v", modifiers: [])`
  は `.disabled(state.sourceURL == nil)` で source 未読込み時は発火しない。
- Save Look の rename / save prompt は AppKit `NSAlert` (modal、独立 keyWindow) で
  実装されているため、その間 main window の toolbar shortcut は発火しない。
- 右レール内に SwiftUI TextField は無し (確認済) なので text input 中の誤爆は無い。
- 既存 `keyboardShortcut(.space, modifiers: [])` (Play/Pause) と同じ前提。

## Compare の意味 (Before / After 定義)

- "Before" (左) = `request.sourceImage` (video) / `CIImage(contentsOf:)` (still) を
  `scaledPreviewSourceImage` だけ通した状態。**source-profile transform は未適用**。
  Apple Log などログ素材は意図的にフラット表示 (= 取り込んだ生に近い)。
- "After" (右) = source-profile transform + grade pipeline 通過後の最終 graded。
- 0.5 split で左右に並ぶ。境界線・ラベル等の overlay は作らない (helper は
  画像合成のみ、ガイドラインは付けない)。
