# Phase 1: Contract & Neutral Plumbing

Date: 2026-05-12 JST
Phase: 1 of 5 (see `strategy.md`)

## Goal

Add `detailSoftness` (range `0…1`, default `0`) to every contract layer that
round-trips Params, with zero behavioral change. The neutrality claim in
Phase 1 is **structural, not pixel-validated**: no renderer, shader, uniform
table, or visual pass reads the key after the change, so the rendered output
of every existing project, Look, preset, and saved patch is unchanged by
construction. Pixel-level A/B validation is deferred to Phase 2 when an
actual render pass lands.
